- Changed what earns a reward party: `music.reward_rule = "animals"` (the new default) gives a party for meeting `music.reward_animals` (8) different animals since the last party, at most one every `music.reward_min_gap` (180 s) from the previous party's end or from start-up. If the animals are met early, the party starts on the first keypress after the gap. Repeats, number keys and non-animal keys never count, so mashing one key earns nothing. The audio engine counts the animal the effect engine actually spawned (`note_animal`, fed by `on_animal`, so F7-F12 dinosaur picks count by name) and `reward_progress` is `distinct / reward_animals`.
- `music.reward_rule = "play"` keeps the seconds-or-presses meter exactly; `config.legacy.toml` sets it. `AudioEngine`'s own constructor default stays `"play"`; the config supplies `"animals"`. The party failsafe (`PARTY_MAX_SECONDS`) is untouched. The new keys are validated in `config.py` and documented in `config.toml`.
