# Silhouette credits

These outlines come from [PhyloPic](https://www.phylopic.org/), a database of
life-form silhouettes built for phylogenetic diagrams. They are the only part of
Lily Pad not drawn by its own code — everything painted **on** them (colour,
shading, patterns, eyes, keyline, the unicorn's horn, the narwhal's tusk, and
all motion) is still procedural.

Every file here is under a **public-domain dedication**, chosen deliberately:
PhyloPic also hosts CC-BY-NC-SA images, and the default image a taxon shows on
the site is often one of those. NonCommercial has no place in this repo — it
would follow anyone who forked it. If you add a silhouette, check the licence on
the **specific image**, not the taxon.

Attribution is not required for any of these. It is given anyway, because many
are by working palaeoartists and scientific illustrators.

## Notes on particular picks

- **unicorn** and **horse** are both *Equus ferus*, and **zebra** is *Equus
  quagga*. Three different images were chosen on purpose so the three do not
  read as the same animal in three colours: the unicorn is a prancing pose with
  an arched neck, the horse a trotting one, the zebra stockier and
  shorter-necked.
- **yak** is a *Bison*. No public-domain yak silhouette exists, and a bison has
  the same horns-and-shoulder-hump read at sprite size.
- **narwhal** has no tusk in *any* public-domain image — the ones that do are
  drawn from above, which is useless for an animal that swims across the
  screen. The tusk is drawn on procedurally, like the unicorn's horn.
- **unicorn** does not exist, so the outline is a horse and the horn is drawn on.

The files are unmodified potrace output as served by the PhyloPic API: solid
black shapes with a real alpha channel, which is exactly what
`effects/animal_stencil.py` needs — it paints *through* that alpha rather than
recolouring pixels, so the outline stays crisp at any size.
